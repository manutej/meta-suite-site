How to run the suite · the recipe, not the menu

The grid tells you what the nine are. This tells you the order to run them in.

The make / keep grid is a menu. On its own it doesn't say where to start, what feeds what, or why the work should get cheaper over time. The order below does — because every step hands a finished output to the next, and the last step feeds the first.

What's happening
1·2Frame. Start warm from last cycle's notes, then ground the gap in real sources.
3·4Shape. Turn the gap into a “how to think” scaffold, then a typed, parallelizable plan.
5·6·7Make. Derive the schema, assemble the bundle, build it to survive contact with reality.
8·9Keep. Review adversarially for one reusable lesson, capture it — then feed it back to step 1.
Sustainable = each step's output is the next step's input, and step 9 writes back into step 1 — so the next pass re-derives nothing.
The four arcs

Nine skills, four moves, one direction.

Each arc ends by handing a named artifact to the next. That hand-off is the whole trick: you never start a step from a blank page, and you never re-derive what an earlier step already settled.

Arc 01 · FrameStart warm, on solid ground
hands off ↓ a grounded brief
1meta-context

Load what the last cycle left behind and decide what to keep in working memory.

→ a warm-start memory scaffold
2meta-research

Ground the specific gap in real, cross-verified sources before shaping anything.

→ a cited brief with confidence
Arc 02 · ShapeTurn the brief into a structure
hands off ↓ an executable plan
3meta-prompting

Lift the gap into a typed “how to think” scaffold that fits the whole category, not one instance.

→ a reusable meta-prompt
4meta-planning

Turn that scaffold into a typed work-unit graph — what runs in parallel, what must wait, where the gates are.

→ a fresh-agent-executable plan
Arc 03 · MakeBuild the thing, built to last
hands off ↓ a shipped artifact
5meta-design

Derive the medium-specific design schema and tokens, then render against them.

→ a schema + the system that makes it
6meta-mvp

Assemble the full deliverable bundle end-to-end when the output is a whole new thing.

→ a WOW-grade bundle
7meta-craft

Hold it to a craft constitution and an evidence-based Definition of Done before it ships.

→ a proven, change-ready artifact
Arc 04 · KeepLearn from it, bank the lesson
hands off ↺ back to step 1
8meta-review

Run adversarial, multi-lens review; return prioritized findings and one reusable lesson.

→ a prioritized fix list + a lesson atom
9meta-compound

Capture that lesson as a durable asset and update the index — so the next cycle finds it and starts cheaper. This writes back into step 1.

↺ feeds meta-context for the next pass
