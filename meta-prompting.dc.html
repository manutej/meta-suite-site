Skill 01 · make axis

meta-prompting

A reusable meta-prompt: how to think about a task category, not a worked example.

// what it does

Instead of writing a fresh prompt per task, write one reusable prompt that teaches a model how to think about a whole category of problems. Give it a scaffold — roles, steps, slots — not examples to imitate.

Because the scaffold is example-agnostic, a model can apply it to itself: refine the prompt, run it, fold the result back in. That recursion is the engine behind the whole suite — and the reason the loop gets sharper instead of merely repeating.

// the scaffold
roles

Who the model is being, and for whom. The stance it takes before it reads a single detail.

steps

The ordered moves for the category — perceive, reason, act, check — independent of any one task.

slots

The holes the specific task fills in. Leave them empty and the same prompt serves the whole category.

// invoke it
/meta-suite:meta-prompting <a task category you keep re-solving>

Returns a reusable meta-prompt — roles, steps, and empty slots — plus a note on how to run it against itself. It never asks you clarifying questions; it infers the category and emits the structure.
