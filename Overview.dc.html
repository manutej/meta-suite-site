Two axes

One axis builds it. One keeps it good.

Every skill sits on one of two axes. The make skills take an idea to a shipped thing. The keep skills make sure it stays good — durable, honest, and improving on its own.

The make axis

Idea → shipped thing

From a spark to a deliverable. These skills shape how a thing gets thought about, planned, designed, and assembled.

prompting planning design mvp
The keep axis

Good, durable, self-improving

After it exists, keep it honest. These skills compound quality, set the bar, stress-test the work, and carry context forward.

compound craft review research context

How it fits together

The two axes close a loop.

build → review → compound → context → sharper next think ↺

The make skills get you to a shipped thing. The keep skills make that thing better and remember why. Review hands a lesson to the compounding map; the map feeds the context scaffold; so your next build starts from everything the last one learned instead of a blank page. Install

Two lines in Claude Code. One line everywhere else.

Recommended · Claude Code plugin
Run inside any Claude Code session (CLI, desktop, web, IDE).
/plugin marketplace add manutej/meta-suite
/plugin install meta-suite@meta-suite
Start a new session, then just describe the task. To call a skill directly, use its namespaced name: /meta-suite:meta-review.
Codex · Cursor · Grok Build · Copilot · Gemini CLI
One command installs all nine skills for the agents you name.
npx skills add manutej/meta-suite --skill '*' -g -a codex -a cursor -a grok
Then invoke with $meta-review in Codex or /meta-review in Cursor and Grok, or just ask.
Claude app · ChatGPT · Grok · any API
Ready-made packages, no build step.
Upload: one zip per skill in dist/upload (claude.ai, Claude Desktop, ChatGPT Skills, Grok Skills, Claude & OpenAI APIs).
No skills support? Paste instructions.md into a Project and attach meta-suite-prompt.md.
