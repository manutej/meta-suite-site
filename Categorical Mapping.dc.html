What's happening · the work and the prompt, one shape
carry ONE PIECE, ONE BLOCK

Each step of the work gets exactly one matching block of instructions. Nothing extra, nothing missing.

connect SAME ORDER

The work runs in an order — research, then outline, then draft. The instructions come in that same order.

follow CHANGE IT, IT FOLLOWS

Add a step — find images — and a matching block appears in the prompt, in the right place. The two sides can't drift apart.

Structure-preserving = the prompt mirrors the work's shape — same pieces, same order — so when the work changes, the prompt changes with it. That's how meta-prompting turns a task into instructions without losing the plot.
